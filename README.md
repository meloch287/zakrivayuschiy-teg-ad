# Закрывающий тег

Учебный проект по макету Яндекс Практикума: восемь карточек о пройденных этапах вёрстки, анимированные лайки и модальное окно сохранения.

Для локального просмотра из папки проекта выполните:

```sh
python3 -m http.server 8155 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8155. Сборка и установка зависимостей не требуются. Сервер нужен для корректной загрузки SVG-символа дискеты.

Кнопки с сердцем и Like переключают отметку. «Сохранить на память» открывает диалог; его можно закрыть кнопкой «ОК» или клавишей Escape. Настройка reduced motion отключает декоративное движение. Все действия доступны с клавиатуры.

Исходная заготовка: [zakrivayuschiy-teg-ad](https://github.com/yandex-praktikum/zakrivayuschiy-teg-ad). [Макет проекта](https://www.figma.com/design/Yg5IFeWSyl6Js98kWROjVP/). Иллюстрация фургона, иконки и фавикон экспортированы из макета. Шрифты входят в официальную заготовку. Подписи карточек описывают учебные действия, без вымышленных личных воспоминаний.

Проверены ширины 320, 375, 768 и 1440 px в Chrome: горизонтального переполнения нет, изображения доступны, лайки и диалог работают, фокус возвращается на кнопку открытия. В WebKit проверены ширины 320, 375 и 1440 px и те же основные действия. Firefox не удалось запустить из-за ошибки тестового профиля, Yandex Browser в окружении не установлен.

Репозиторий проекта: https://github.com/meloch287/zakrivayuschiy-teg-ad.
